🎯 Что такое ансамбль?

Ансамбль (от французского ensemble — «вместе, совокупность») в машинном обучении — это набор моделей, объединённых для получения более качественного предсказания, чем каждая модель по отдельности.

Простыми словами: вместо одной умной модели мы обучаем много «слабых» моделей и объединяем их мнения. В большинстве случаев такой «коллектив» работает лучше, чем любой отдельный эксперт.

📐 Формальное определение

Дано:

  • Обучающая выборка: D = {(x₁, y₁), (x₂, y₂), ..., (xₙ, yₙ)}
  • Базовые модели (base learners): h₁, h₂, ..., hₘ
  • Мета-алгоритм объединения: F(h₁, h₂, ..., hₘ)
H(x) = F(h₁(x), h₂(x), ..., hₘ(x))

🧠 Философия «мудрости толпы»

🐂 Аналогия из жизни Представьте, что вы хотите оценить вес быка на ярмарке. Есть два подхода.

👨‍🌾 Подход 1: один эксперт

Спросите одного опытного фермера. Он даст оценку, например, 900 кг. Но может ошибиться на 100 кг.

👥 Подход 2: множество экспертов

Спросите 100 случайных людей (не экспертов) — туристов, детей, стариков. Каждый даст очень грубую оценку. Но если усреднить все 100 оценок — получится очень точный результат!

💡 Почему это работает? Это явление называется «мудрость толпы» (Wisdom of the Crowd). Фундамент — теорема Кондорсе о жюри присяжных (1785): если каждый член жюри принимает правильное решение с вероятностью p > 0.5, то вероятность правильного решения большинства стремится к 1 при росте числа членов жюри.

🎒 Bagging (Bootstrap Aggregating)

📋 Идея

  1. Из обучающей выборки случайно с возвращением берётся подвыборка того же размера
  2. На этой подвыборке обучается базовая модель
  3. Шаги 1-2 повторяются M раз — получаем M моделей
  4. Итоговое предсказание = усреднение (регрессия) или голосование (классификация)

⚙️ Особенности Bagging

  • ✅ Уменьшает дисперсию, не меняя смещение
  • ✅ Хорошо работает со «слабыми» моделями с высокой дисперсией (глубокие деревья)
  • ❌ Плохо работает с устойчивыми моделями (линейная регрессия)
  • ✅ Легко параллелизуется
06

🚀 Boosting

📋 Идея

  1. Обучается первая модель (обычно простая)
  2. Анализируются объекты, где модель ошиблась
  3. Обучается вторая модель, фокусируясь на ошибках первой
  4. Процесс повторяется — каждая новая модель исправляет ошибки предыдущих
  5. Итоговое предсказание = взвешенная сумма всех моделей

⚙️ Особенности Boosting

  • ✅ Уменьшает смещение
  • ✅ Работает с «слабыми» моделями (неглубокие деревья)
  • ❌ Чувствителен к шуму и выбросам
  • ❌ Требует последовательного обучения (сложнее параллелить)

🎯 Типы Boosting

CatBoostУпорядоченный boosting + авто-категорииCatBoost

🏗️ Stacking

📋 Идея

  1. Обучается несколько разнородных базовых моделей (LR, DT, SVM...)
  2. Их предсказания подаются на вход мета-модели
  3. Мета-модель учится комбинировать предсказания базовых

⚙️ Особенности Stacking

  • ✅ Работает с разнородными моделями
  • ✅ Мета-модель учится оптимально взвешивать базовые
  • ⚠️ Требует кросс-валидации для избежания утечки
  • ✅ Может дать наибольший прирост качества

🌲 Random Forest

📐 Алгоритм

  1. Для каждого из M деревьев:
    • Взять bootstrap-выборку (n объектов с возвращением)
    • Построить дерево, но на каждом разбиении рассматривать случайное подмножество из √p признаков
  2. Итоговое предсказание = голосование (классификация) или среднее (регрессия)

⭐ Ключевые особенности

  • Декорареляция деревьев
  • OOB-оценка (бесплатная валидация)
  • Важность признаков
  • Устойчивость к выбросам

🚀 XGBoost

Тип: Gradient Boosting · Автор: Тянци Чен (2014) · Основной инструмент победителей Kaggle

⭐ Ключевые особенности

  1. Регуляризация: штраф за сложность дерева
  2. Приближённое решение: второй порядок Тейлора
  3. Sparsity-aware: обрабатывает пропуски автоматически
  4. Column Block: параллельное обучение
  5. Cache-aware: оптимизация памяти

⚡ LightGBM

Тип: Gradient Boosting · Автор: Microsoft (2017) · Быстрее XGBoost в 10-20 раз

⭐ Ключевые особенности

  1. Leaf-wise рост дерева вместо level-wise:
    XGBoost: растёт уровень за уровнем
    LightGBM: растёт самый «перспективный» лист
    Результат: меньше деревьев, выше точность
  2. GOSS: отбрасывает объекты с малым градиентом
  3. EFB: объединяет разреженные признаки
  4. Гистограммный алгоритм: биннинг признаков

🐱 CatBoost

Тип: Gradient Boosting · Автор: Яндекс (2017) · Лучший для данных с категориями

⭐ Ключевые особенности

  1. Автоматическая обработка категорий:
    • Не требует One-Hot Encoding
    • Использует упорядоченное целевое кодирование
  2. Упорядоченный boosting:
    • Снижает смещение в оценке градиента
    • Помогает бороться с переобучением
  3. Симметричные деревья: все узлы на уровне используют одинаковое разбиение
  4. GPU-обучение из коробки

⚖️ Преимущества и недостатки

✅ Преимущества

  • Высокая точность — превосходят одиночные модели
  • Устойчивость к переобучению — особенно bagging
  • Работа с дисбалансом — через class_weight
  • Универсальность — таблицы, тексты
  • Автоматический отбор признаков
  • Обработка пропусков — XGBoost, LightGBM, CatBoost
  • Масштабируемость — на больших данных

❌ Недостатки

  • Сложность интерпретации — «чёрный ящик» (решается через SHAP)
  • Вычислительная сложность — особенно boosting
  • Память — много деревьев = много памяти
  • Требует тюнинга — гиперпараметров много
  • Не всегда лучше одиночных — на малых данных может переобучаться
⚠️ Когда ансамбли НЕ нужны
  • Мало данных (< 1000 объектов) — лучше линейные модели
  • Простая задача — одиночное дерево или логистическая регрессия справится
  • Нужна максимальная интерпретируемость — используйте линейные модели
  • Real-time инференс с жёстким ограничением — рассмотрите одиночное дерево

🎛️ Тюнинг гиперпараметров

💡 Почему это важно? Гиперпараметры определяют поведение модели. Неправильный выбор — катастрофическое качество. Правильный — рост на 3-10% метрики.

🎯 Optuna — современный стандарт

Optuna использует TPE (Tree-structured Parzen Estimator) — байесовский подход, который после каждого испытания строит вероятностную модель и предлагает следующее значение там, где ожидается улучшение.

Основные компоненты:

  • Objective function — что оптимизируем
  • Study — процесс оптимизации
  • Trial — одно испытание
  • suggest_int / float / categorical — пространство поиска

Преимущества:

  • ⚡ В 10 раз быстрее GridSearch
  • 🔧 Работает с условными параметрами
  • 📊 Визуализация процесса
  • ✂️ Pruning — остановка бесперспективных
  • 🔗 Интеграция со sklearn, XGBoost

🔍 SHAP — интерпретация моделей

🚨 Проблема «чёрного ящика» Ансамбли — мощные, но непрозрачные. Регулятор спрашивает: «Почему вы отклонили кредит?». Ответ «потому что так решила модель XGBoost» — не подходит.

💡 Что такое SHAP?

SHAP (SHapley Additive exPlanations) — метод интерпретации, основанный на теории кооперативных игр.

Идея: предсказание — это «приз», который нужно разделить между «игроками» (признаками) по их вкладу. SHAP считает справедливый вклад каждого признака через значения Шепли.

📐 Значение Шепли

φᵢ = Σ [|S|!(|N|-|S|-1)!/|N|!] · [v(S∪{i}) - v(S)]

где N — все признаки, S — подмножество, v(S) — ценность коалиции

⚙️ Свойства SHAP

СвойствоЧто означает
Локальная точностьСумма SHAP = предсказание − базовое значение
ОтсутствиеЕсли признак не влияет, SHAP = 0
СимметрияОдинаковые признаки = одинаковые SHAP
СогласованностьЕсли признак стал важнее, SHAP не уменьшится

📖 Как читать Summary plot

  • Ось Y: признаки по важности
  • Ось X: SHAP-значения (влияние)
  • Цвет: значение признака (красный = высокое, синий = низкое)
  • Каждая точка: один объект
Интерпретация:
🔴 Красные точки справа → высокие значения увеличивают предсказание
🔵 Синие точки слева → низкие значения уменьшают предсказание

💰 Матрица стоимости (German Credit)

В датасете German Credit Data используется матрица стоимости, которая определяет «цену» ошибок.

📊 Матрица стоимости

Предсказано: GoodПредсказано: Bad
Реально: Good01
Реально: Bad50

💡 Интерпретация

  • Ошибка 1 (FP): «Хороший клиент признан плохим» — банк теряет прибыль (1 единица)
  • Ошибка 2 (FN): «Плохой клиент признан хорошим» — банк теряет деньги (5 единиц)

🎯 Как учесть в модели?

1. Через class_weight

Увеличить вес класса Bad в 5 раз

2. Через порог

Сместить порог, чтобы лучше ловить Bad

3. Через метрику

Оптимизировать не accuracy, а стоимость

💡 Оптимизация порога Стандартный порог 0.5 не оптимален. Перебирая пороги от 0.1 до 0.9, находим тот, при котором суммарная стоимость минимальна. Это критично для бизнеса: один правильный порог может сэкономить миллионы рублей.

💻 Ячейка 6: XGBoost, LightGBM, CatBoost

# ============================================================ # ЯЧЕЙКА 6: СРАВНЕНИЕ XGBOOST, LIGHTGBM, CATBOOST # ============================================================ def evaluate_model(model, X_train, X_test, y_train, y_test, name): """Обучает модель, замеряет время, считает метрики.""" start = time.time() model.fit(X_train, y_train) train_time = time.time() - start y_pred = model.predict(X_test) y_proba = model.predict_proba(X_test)[:, 1] return { 'Model': name, 'Time (sec)': round(train_time, 3), 'Accuracy': round(accuracy_score(y_test, y_pred), 4), 'Precision': round(precision_score(y_test, y_pred), 4), 'Recall': round(recall_score(y_test, y_pred), 4), 'F1': round(f1_score(y_test, y_pred), 4), 'ROC-AUC': round(roc_auc_score(y_test, y_proba), 4) } # --- XGBoost --- xgb_model = XGBClassifier( n_estimators=200, max_depth=6, learning_rate=0.1, subsample=0.9, colsample_bytree=0.9, gamma=0.1, reg_alpha=0.1, reg_lambda=1.0, random_state=42 ) results_xgb = evaluate_model(xgb_model, X_train, X_test, y_train, y_test, 'XGBoost') # --- LightGBM --- lgbm_model = LGBMClassifier( n_estimators=200, num_leaves=31, max_depth=7, learning_rate=0.05, subsample=0.8, colsample_bytree=0.8, min_child_samples=20, random_state=42, verbose=-1 ) results_lgbm = evaluate_model(lgbm_model, X_train, X_test, y_train, y_test, 'LightGBM') # --- CatBoost --- cat_model = CatBoostClassifier( iterations=200, depth=6, learning_rate=0.1, l2_leaf_reg=3, random_state=42, verbose=0 ) results_cat = evaluate_model(cat_model, X_train, X_test, y_train, y_test, 'CatBoost') # --- Сводная таблица --- results_df = pd.DataFrame([results_xgb, results_lgbm, results_cat]) print(results_df.to_string(index=False))

💻 Ячейка 7: Оптимизация LightGBM с Optuna

# ============================================================ # ЯЧЕЙКА 7: ОПТИМИЗАЦИЯ LIGHTGBM С ПОМОЩЬЮ OPTUNA # ============================================================ optuna.logging.set_verbosity(optuna.logging.WARNING) def objective(trial): """Objective-функция: обучает LightGBM и возвращает CV-метрику.""" params = { 'n_estimators': trial.suggest_int('n_estimators', 50, 500, step=50), 'num_leaves': trial.suggest_int('num_leaves', 10, 100, step=5), 'max_depth': trial.suggest_int('max_depth', 3, 12), 'learning_rate': trial.suggest_float('learning_rate', 0.01, 0.3, log=True), 'subsample': trial.suggest_float('subsample', 0.5, 1.0), 'colsample_bytree': trial.suggest_float('colsample_bytree', 0.5, 1.0), 'min_child_samples': trial.suggest_int('min_child_samples', 5, 50), 'reg_alpha': trial.suggest_float('reg_alpha', 1e-3, 10, log=True), 'reg_lambda': trial.suggest_float('reg_lambda', 1e-3, 10, log=True), } model = LGBMClassifier(**params, random_state=42, verbose=-1) cv_scores = cross_val_score( model, X_train, y_train, cv=StratifiedKFold(5, shuffle=True, random_state=42), scoring='roc_auc' ) return cv_scores.mean() # --- Запуск оптимизации --- study = optuna.create_study(direction='maximize') study.optimize(objective, n_trials=30, show_progress_bar=True) print(f"Best ROC-AUC: {study.best_value:.4f}") for key, value in study.best_params.items(): print(f" {key}: {value}") # --- Обучение с лучшими параметрами --- best_lgbm = LGBMClassifier(**study.best_params, random_state=42, verbose=-1) best_lgbm.fit(X_train, y_train) y_proba_best = best_lgbm.predict_proba(X_test)[:, 1] print(f"ROC-AUC: {roc_auc_score(y_test, y_proba_best):.4f}")

💻 Ячейка 8: SHAP — интерпретация

# ============================================================ # ЯЧЕЙКА 8: SHAP — ИНТЕРПРЕТАЦИЯ LIGHTGBM # ============================================================ # --- Создаём explainer --- explainer = shap.TreeExplainer(best_lgbm) # TreeExplainer — быстрый алгоритм для древовидных моделей. # Почему не KernelExplainer: он медленнее в 100-1000 раз. # --- Вычисляем SHAP-значения --- shap_values = explainer.shap_values(X_test) # Для бинарной классификации shap_values — список из двух массивов. if isinstance(shap_values, list): shap_values_class1 = shap_values[1] else: shap_values_class1 = shap_values print(f"Форма SHAP-значений: {shap_values_class1.shape}") # --- Summary plot --- shap.summary_plot(shap_values_class1, X_test, plot_type="dot") # Каждая точка — один объект. # Ось X — SHAP-значение (влияние на предсказание). # Цвет — значение признака. # --- Bar plot (важность) --- shap.summary_plot(shap_values_class1, X_test, plot_type="bar") # --- Waterfall plot --- worst_idx = np.argmax(y_proba_best) # Индекс объекта с наибольшей вероятностью "Bad". shap.plots.waterfall( shap.Explanation( values=shap_values_class1[worst_idx], base_values=explainer.expected_value[1] if isinstance(explainer.expected_value, list) else explainer.expected_value, data=X_test.iloc[worst_idx], feature_names=X_test.columns.tolist() ) ) # --- Dependence plot --- top_feature = feature_importance.iloc[0]['Feature'] shap.dependence_plot(top_feature, shap_values_class1, X_test, interaction_index=None)

💻 Ячейка 9: Оптимизация порога с учётом стоимости

# ============================================================ # ЯЧЕЙКА 9: ОПТИМИЗАЦИЯ ПОРОГА С УЧЁТОМ МАТРИЦЫ СТОИМОСТИ # ============================================================ def cost_metric(y_true, y_pred): """Считает общую стоимость ошибок по матрице стоимости.""" cost_matrix = np.array([[0, 1], [5, 0]]) # Строки — истина, столбцы — предсказание. # [0,0] = 0 (TN), [0,1] = 1 (FP) # [1,0] = 5 (FN), [1,1] = 0 (TP) total_cost = 0 for true, pred in zip(y_true, y_pred): total_cost += cost_matrix[true, pred] return total_cost # --- Подбор порога --- thresholds = np.arange(0.05, 0.95, 0.05) costs = [] for thresh in thresholds: y_pred_thresh = (y_proba_best >= thresh).astype(int) # (prob >= thresh) — True/False. cost = cost_metric(y_test.values, y_pred_thresh) costs.append(cost) # --- Результаты --- best_idx = np.argmin(costs) best_threshold = thresholds[best_idx] print(f"Стандартный порог 0.5: стоимость = {cost_metric(y_test.values, (y_proba_best >= 0.5).astype(int))}") print(f"Оптимальный порог: {best_threshold:.2f}") print(f"Минимальная стоимость: {min(costs)}") # --- Визуализация --- plt.figure(figsize=(12, 5)) plt.plot(thresholds, costs, color='#00d4ff', linewidth=2.5, marker='o') plt.axvline(x=best_threshold, color='#ff006e', linestyle='--', label=f'Оптимум = {best_threshold:.2f}') plt.xlabel('Порог классификации') plt.ylabel('Стоимость ошибок') plt.legend() plt.show()

💎 Ключевые выводы

🔑 Что запомнить

  1. Ансамбль > одиночная модель. «Мудрость толпы» работает.
  2. Bagging снижает variance, boosting снижает bias.
  3. Random Forest — простой, устойчивый, для baseline.
  4. XGBoost — универсальный, точный, для соревнований.
  5. LightGBM — быстрый, для больших данных.
  6. CatBoost — лучший для категориальных признаков.
  7. Optuna — современный стандарт тюнинга.
  8. SHAP — мощный инструмент интерпретации.
  9. Матрица стоимости — учёт бизнес-цены ошибок.
