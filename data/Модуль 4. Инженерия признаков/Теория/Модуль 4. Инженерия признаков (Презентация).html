🎯 Что такое Feature Engineering?

Инженерия признаков — это процесс создания новых признаков из существующих данных, чтобы улучшить качество и точность моделей машинного обучения. Это не просто техническая процедура, а творческий процесс, требующий понимания предметной области.

💡 Известное выражение

«Признаки важнее алгоритмов. Хорошие признаки + простая модель = отличный результат. Плохие признаки + сложная модель = плохой результат.»

📋 Основные задачи

  • Извлечение скрытой информации — возраст из даты рождения, район из адреса
  • Повышение нелинейности — логарифмы, полиномы
  • Уменьшение размерности — удаление шумных признаков
  • Работа с нестандартными данными — тексты, гео, временные ряды

🎯 Почему это важно

Инвестиции времени в Feature Engineering окупаются значительно большим приростом качества, чем выбор более сложного алгоритма.

📝 Тексты: Bag of Words (BoW)

В реальных проектах часто встречается текст: описания инцидентов, техническая документация, отчёты о бурении, логи ошибок. Мы не можем подать текст напрямую в модель — нужны числовые признаки.

📋 Как работает Bag of Words

  1. Строим словарь всех уникальных слов в корпусе
  2. Для каждого документа считаем, сколько раз каждое слово в нём встречается
  3. Получаем числовой вектор частот

✅ Плюсы

  • Простота реализации
  • Интерпретируемость
  • Быстро работает

❌ Минусы

  • Не учитывает важность слов
  • Частые слова («the», «a») доминируют
  • Теряется порядок слов
BoW(d) = [count(w₁, d), count(w₂, d), ..., count(wₙ, d)]
05

📝 Тексты: TF-IDF

TF-IDF учитывает важность слова. Идея: если слово часто встречается в конкретном документе, но редко в других документах корпуса, то оно важно именно для этого документа.

📐 Компоненты

TF (Term Frequency) — как часто слово встречается в документе (нормируется на длину).

IDF (Inverse Document Frequency) — как редко слово встречается во всех документах (логарифм).

💡 Идея

Слово «поглощение» может быть редким в целом, но критически важным в описании конкретного инцидента.

Слово «drilling» встречается везде — его TF-IDF будет ниже.

TFIDF(t, d) = TF(t, d) × IDF(t)
IDF(t) = log(N / DF(t))
N — общее число документов, DF(t) — число документов, содержащих слово t

🗺️ Гео: Расстояние Хаверсина

Координаты (широта и долгота) — это не просто числа. Земля круглая, поэтому нельзя просто вычесть координаты. Один градус широты на экваторе и на полюсе — это разные расстояния в километрах.

📐 Формула Haversine

a = sin²(Δφ/2) + cos(φ1)·cos(φ2)·sin²(Δλ/2)
c = 2 · atan2(√a, √(1−a))
d = R · c

R — радиус Земли (6371 км), φ — широта, λ — долгота

🎯 Зачем нужен

Скважины, расположенные близко друг к другу, могут иметь схожие геологические условия. Расстояние до центра может коррелировать с типом геологии.

💡 Где применяется

  • Нефтегаз: расстояние между скважинами
  • Логистика: расстояние между пунктами
  • Геомаркетинг: расстояние до магазина

🗺️ Гео: Кластеризация DBSCAN

DBSCAN (Density-Based Spatial Clustering of Applications with Noise) находит плотные скопления точек в пространстве.

⚙️ Параметры

  • eps — радиус окрестности (в градусах или км)
  • min_samples — минимум точек для формирования кластера

Защищает от одиночных выбросов.

🎯 Как работает

  1. Для каждой точки считаем соседей в радиусе eps
  2. Если соседей ≥ min_samples — точка становится ядром
  3. Все соседи присоединяются к кластеру
  4. Одиночные точки — шум (метка -1)

💡 Зачем нужен в нефтегазе

  • 🔍 Найти аномальные скважины — далеко от остальных
  • 🎯 Выделить кусты скважин — кластеры
  • 📊 Скважины в одном кластере имеют схожие свойства

📅 Время: Лаги (Lags)

Лаг — это сдвиг значения на предыдущие шаги. Метод df['value'].shift(1) сдвигает значения на 1 строку вниз.

🎯 Зачем нужны лаги

Если мы хотим предсказать давление завтра, нам полезно знать давление вчера. Временные ряды обладают автокорреляцией — значения в соседние моменты времени связаны.

💡 Пример

Если TARGET_POROSITY вчера была 0.25, сегодня, вероятно, будет близка к этому значению.

# Лаги: сдвигаем значения на предыдущие шаги df['POROSITY_LAG_1'] = df['TARGET_POROSITY'].shift(1) df['POROSITY_LAG_2'] = df['TARGET_POROSITY'].shift(2) # shift(1) — вчерашнее значение, shift(2) — позавчерашнее # Заполняем образовавшиеся NaN df = df.fillna(0)
⚠️ После shift() в начале ряда появляются NaN — их нужно заполнить нулями или средним.
10

📅 Время: Скользящие окна

Скользящее окно — это среднее (или другая функция) за последние N шагов. Метод df['value'].rolling(window=7).mean().

🎯 Зачем нужны

Сглаживает шум и показывает тренд. Скользящее среднее за 7 дней убирает дневные колебания и оставляет недельный тренд.

💡 Другие функции

  • rolling().std() — волатильность
  • rolling().min() / max() — экстремумы
  • rolling().sum() — накопление
# Скользящее среднее за 7 шагов df['POROSITY_ROLLING_MEAN_7'] = ( df['TARGET_POROSITY'].rolling(window=7).mean() ) # Разница между текущим и предыдущим значением df['POROSITY_DIFF'] = df['TARGET_POROSITY'].diff() # diff() показывает скорость изменения признака
💡 Если давление резко выросло — это может быть предвестником аварии.

💻 Код: Расстояние Хаверсина

# ============================================================ # РАССТОЯНИЕ ХАВЕРСИНА # ============================================================ def haversine_distance(lat1, lon1, lat2, lon2): """Рассчитывает расстояние между двумя точками на Земле в км.""" R = 6371.0 # Радиус Земли в км # Перевод градусов в радианы lat1, lon1, lat2, lon2 = map(np.radians, [lat1, lon1, lat2, lon2]) # Формула Хаверсина dlat = lat2 - lat1 dlon = lon2 - lon1 a = np.sin(dlat/2)**2 + np.cos(lat1) * np.cos(lat2) * np.sin(dlon/2)**2 c = 2 * np.arctan2(np.sqrt(a), np.sqrt(1-a)) return R * c # Расстояние в км # Центр (например, главный офис) CENTER_LAT, CENTER_LON = 38.5, -98.0 df['DIST_FROM_CENTER'] = haversine_distance( df['LAT'], df['LON'], CENTER_LAT, CENTER_LON ) # Расстояние до центра может коррелировать с геологией print(df[['LAT', 'LON', 'DIST_FROM_CENTER']].head())

💎 Ключевые инсайты

1️⃣
Feature Engineering важнее выбора алгоритма. Хорошие признаки + простая модель часто лучше, чем плохие признаки + сложная модель.
2️⃣
DBSCAN находит аномалии без учителя. Метка -1 означает шум — такие объекты могут быть выбросами или требовать отдельного анализа.
3️⃣
TF-IDF использует текстовые логи для прогноза. Даже небольшой текст может дать полезные признаки.
4️⃣
Лаги и rolling критичны для временных рядов. Они позволяют модели учитывать историю и тренды.
5️⃣
Haversine — обязательный инструмент для геоданных. Нельзя просто вычитать координаты.

🚀 Что дальше изучать

🎯 Target Encoding

Для категориальных признаков с высокой кардинальностью. Позволяет избежать взрыва размерности при One-Hot Encoding.

📝 Эмбеддинги

Word2Vec, BERT для более глубокой обработки текста. Позволяют улавливать семантический смысл слов.

📅 GroupKFold

Кросс-валидация по группам для геоданных. Чтобы одна скважина не была в train и test одновременно.

📊 Feature Store

Версионирование признаков в продакшене. Позволяет переиспользовать признаки между проектами.
