Введение в регрессию

Что такое регрессия?

Регрессия — это класс задач машинного обучения с учителем, в которых целевая переменная является непрерывной величиной. Модель учится предсказывать число, а не метку класса.

Математическая постановка

Дано: обучающая выборка

D = {(x₁, y₁), ..., (xₙ, yₙ)}
  • xᵢ ∈ ℝᵖ — вектор из p признаков
  • yᵢ ∈ ℝ — непрерывная целевая

Найти: функцию f: ℝᵖ → ℝ, минимизирующую ошибку предсказания.

ЧАСТЬ 2

Линейная регрессия и OLS

Модель линейной регрессии

ŷ = w₀ + w₁·x₁ + w₂·x₂ + ... + wₚ·xₚ

где w₀ — смещение (bias), w₁,...,wₚ — веса (коэффициенты).

В матричной форме

ŷ = X·w
  • X ∈ ℝⁿˣ⁽ᵖ⁺¹⁾ — матрица признаков
  • w ∈ ℝᵖ⁺¹ — вектор весов
  • n — число объектов, p — число признаков

Идея метода

Модель предполагает линейную зависимость целевой от признаков. Каждый признак влияет на целевую независимо с весом wⱼ.

Метод наименьших квадратов (OLS)

OLS (Ordinary Least Squares) — находит веса, при которых сумма квадратов отклонений предсказаний от истинных значений минимальна.

Функция потерь (MSE)

L(w) = (1/n) · Σᵢ (yᵢ − ŷᵢ)²

Аналитическое решение

Чтобы найти минимум, берём производную по w и приравниваем к нулю:

ŵ = (XᵀX)⁻¹·Xᵀ·y

Это нормальное уравнение. Работает, если XᵀX обратима.

⚠️ Проблемы OLS
  • Переобучение при p ≈ n или p > n
  • Мультиколлинеарность → XᵀX плохо обусловлена
  • Выбросы сильно искажают веса
  • Скошенность целевой нарушает предпосылки

Свойства OLS-оценки

🎯 Несмещённость

E[ŵ] = wtrue при выполнении предпосылок.

⚡ Эффективность

Наименьшая дисперсия (теорема Гаусса-Маркова).

📈 Состоятельность

ŵ → wtrue при n → ∞.

📋 Предпосылки

Линейность, независимость, E[ε|x]=0, гомоскедастичность, нет мультиколлинеарности.

ЧАСТЬ 3

Регуляризация: Ridge, Lasso, ElasticNet

Зачем нужна регуляризация?

🚨 При большом числе признаков (в House Prices — 79) OLS-решение переобучается: модель запоминает шум в обучающих данных, а на новых данных показывает плохой результат.

⚠️ Симптомы переобучения

  • Ошибка на train очень низкая
  • Ошибка на test высокая
  • Веса модели огромные по модулю
  • Модель чувствительна к малейшим изменениям

✅ Идея регуляризации

Добавить штраф за большие веса к функции потерь.

L = MSE + α · Штраф(w)

Это заставляет модель искать простое решение.

Ridge-регрессия (L2)

LRidge(w) = MSE + α · Σⱼ wⱼ²

Аналитическое решение:

ŵ = (XᵀX + αI)⁻¹·Xᵀ·y

Добавление αI гарантирует обратимость матрицы XᵀX даже при мультиколлинеарности.

  • Веса уменьшаются, но не обнуляются
  • Хорошо работает при мультиколлинеарности
  • Не выполняет отбор признаков
  • Эквивалентна MAP-оценке с гауссовским априорным распределением

Lasso-регрессия (L1)

LLasso(w) = MSE + α · Σⱼ |wⱼ|

L1-штраф имеет «углы» на осях. При оптимизации минимум часто попадает именно в угол — некоторые веса точно обнуляются.

  • Автоматический отбор признаков
  • Разреженное решение (sparse)
  • Устойчивость к выбросам
  • Эквивалентна MAP с лапласовским априорным
⚠️ При сильно коррелированных признаках Lasso выбирает произвольный — может оставить «не тот».

Регуляризация (продолжение)

Геометрическая интерпретация

Регуляризация — это ограничение на область допустимых весов. Форма ограничения определяет поведение:

⭕ Ridge (L2)

Ограничение: ||w||₂² ≤ t — круг (сфера в p-мерном пространстве).

Минимум MSE + штраф обычно касается границы круга — обе координаты ненулевые.

➡️ Веса уменьшаются, но не обнуляются.

💎 Lasso (L1)

Ограничение: ||w||₁ ≤ t — ромб.

У ромба есть вершины на осях. Минимум часто попадает в угол — одна координата обнуляется.

➡️ Автоматический отбор признаков!

🎯 Именно форма ограничения (круг vs ромб) объясняет разницу в поведении Ridge и Lasso.

ElasticNet — компромисс

L(w) = MSE + α · (ρ·Σ|wⱼ| + (1−ρ)/2 · Σwⱼ²)

где α — общая сила регуляризации, ρ ∈ [0, 1] — баланс L1/L2.

  • ρ = 0 → чистый Ridge
  • ρ = 1 → чистый Lasso
  • 0 < ρ < 1 → компромисс

Преимущества

  • Работает лучше Lasso при коррелированных признаках
  • Работает лучше Ridge при большом числе признаков
  • Стабильнее Lasso
  • Может выбрать группу коррелированных признаков

Сравнение методов

МетодШтрафОтборМультикол.Гиперпар.
OLS—❌❌—
RidgeL2❌✅α
LassoL1✅⚠️α
ElasticNetL1+L2✅✅α, ρ

📊 Ridge

Когда все признаки полезны, но есть мультиколлинеарность.

🎯 Lasso

Когда нужно уменьшить число признаков.

🔀 ElasticNet

Когда много коррелированных признаков — золотая середина.

💡 Выбор α: чем больше α — тем сильнее штраф. При α → 0 получаем OLS. При α → ∞ все веса → 0.

Обработка выбросов

🔢 Метод IQR

IQR = Q₃ − Q₁

Границы:

  • Нижняя: Q₁ − 1.5·IQR
  • Верхняя: Q₃ + 1.5·IQR

Не требует нормальности, устойчив к выбросам.

📊 Z-score

z = (x − μ) / σ

Правило: |z| > 3 → выброс.

Предполагает нормальность. Плохо работает на скошенных данных.

🔧 Модифицированный Z-score

M = 0.6745 · (x − median) / MAD

Использует медиану и MAD вместо среднего и std. Устойчив к выбросам.

🎯 В House Prices

Известные выбросы по документации Kaggle:

  • GrLivArea > 4000 кв. футов
  • SalePrice < $300 000

Удаляем только из train!

Предобработка (продолжение)

Логарифмирование скошенной целевой

⚠️ Проблема скошенности

SalePrice имеет правую асимметрию (skew ≈ 1.88):

  • Большинство домов дешёвые
  • Несколько домов очень дорогие
  • Распределение далеко от нормального

Последствия: гетероскедастичность, большое влияние выбросов.

✅ Решение: log1p

y' = log(1 + y)

Обратное:

y = exp(y') − 1

skew после: ≈ 0.12 — почти нормальное!

⚠️ Важно: после логарифмирования метрики (RMSE) считаются в лог-пространстве. Для реального RMSE в долларах используйте np.expm1(predictions).

Метрики и валидация

Метрики регрессии

📉 MSE — Mean Squared Error

MSE = (1/n)·Σ(yᵢ − ŷᵢ)²

Штрафует большие ошибки сильнее. Чувствителен к выбросам.

📈 RMSE

RMSE = √MSE

В единицах целевой (долларах). Чувствителен к выбросам.

📊 MAE

MAE = (1/n)·Σ|yᵢ − ŷᵢ|

Устойчива к выбросам. Соответствует медианной ошибке.

🎯 R²

R² = 1 − SS_res / SS_tot

Доля объяснённой дисперсии. 0..1 (может быть < 0).

Кросс-валидация (K-Fold)

⚠️ Проблема одного split

  • Оценка зависит от случайности
  • Маленький датасет → нестабильные метрики
  • Нет информации о разбросе качества

✅ Решение: K-Fold

  1. Разбить данные на K фолдов
  2. Обучить K раз (каждый фолд побывает в test)
  3. Усреднить метрики

from sklearn.model_selection import cross_val_score, KFold

kf = KFold(n_splits=5, shuffle=True, random_state=42)
scores = cross_val_score(ridge, X_train_scaled, y_train,
                          cv=kf, scoring='neg_root_mean_squared_error')

print(f"RMSE по фолдам: {-scores}")
print(f"Среднее: {-scores.mean():.4f} ± {scores.std():.4f}")

Подбор гиперпараметров (GridSearchCV)

📋 GridSearchCV

Перебор всех комбинаций из сетки параметров.

➕ Надёжно · ➖ Медленно

🎲 RandomizedSearchCV

Случайные N комбинаций из распределений.

➕ Быстро · ➖ Может пропустить оптимум

from sklearn.model_selection import GridSearchCV

# Сетка значений alpha для Ridge
ridge_params = {'alpha': [0.001, 0.01, 0.1, 1.0, 10.0, 100.0]}

ridge_grid = GridSearchCV(
    Ridge(random_state=42),
    ridge_params,
    cv=kf,
    scoring='neg_root_mean_squared_error',
    n_jobs=-1  # все CPU
)
ridge_grid.fit(X_train_scaled, y_train)

print(f"Best alpha: {ridge_grid.best_params_['alpha']}")
print(f"Best RMSE: {-ridge_grid.best_score_:.4f}")

Диагностика и интерпретация

Утечка данных (Data Leakage)

🚨 Утечка данных — ситуация, когда информация из test «просачивается» в train через preprocessing. Модель показывает нереально высокие метрики, но в продакшене «падает».

❌ Типичные ошибки

  • scaler.fit_transform(X_all) до split
  • Вычисление медианы на всём датасете
  • Target Encoding до split
  • Feature selection по всем данным
  • Удаление выбросов из test

✅ Правильно

  • Сначала train_test_split
  • fit только на train
  • transform на test с train-параметрами
  • Использовать Pipeline
  • Target Encoding внутри CV
# ❌ НЕПРАВИЛЬНО — утечка!
scaler = StandardScaler()
X_all_scaled = scaler.fit_transform(X_all)  # fit на всех данных!
X_train, X_test, y_train, y_test = train_test_split(X_all_scaled, y)

# ✅ ПРАВИЛЬНО
X_train, X_test, y_train, y_test = train_test_split(X, y)
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)  # только train!
X_test_scaled = scaler.transform(X_test)         # transform на test

Анализ остатков

Остатки: eᵢ = yᵢ − ŷᵢ. Их анализ показывает, адекватна ли модель.

📊 Что проверять

  1. Среднее ≈ 0 — нет систематической ошибки
  2. Нормальность — QQ-plot
  3. Гомоскедастичность — разброс постоянный
  4. Отсутствие автокорреляции — Durbin-Watson

Переобучение и недообучение

📉 Underfitting

Train error: высокий
Test error: высокий

Модель слишком простая.

Решение: усложнить модель, больше признаков, меньше регуляризации.

✅ Optimum

Train error: низкий
Test error: низкий

Модель обобщает.

Кросс-валидация даёт стабильные метрики.

📈 Overfitting

Train error: очень низкий
Test error: высокий

Модель запомнила шум.

Решение: регуляризация, больше данных, упрощение.

Важность признаков

📊 Коэффициенты линейных моделей

model.coef_[0] — веса признаков.

  • Положительный → повышает предсказание
  • Отрицательный → понижает

⚠️ Работает только после масштабирования!

🎯 Lasso обнуляет

Lasso автоматически удаляет неинформативные признаки.

Если Lasso обнулил N признаков — они не влияют на целевую.

➡️ Это встроенный отбор признаков.

# Коэффициенты Ridge
coef_df = pd.DataFrame({
    'Feature': feature_cols,
    'Coefficient': ridge_model.coef_
}).sort_values('Coefficient', ascending=False)

# Визуализация ТОП-30
top_features = pd.concat([coef_df.head(15), coef_df.tail(15)])
colors = ['#2ecc71' if c > 0 else '#e74c3c' for c in top_features['Coefficient']]
plt.barh(top_features['Feature'], top_features['Coefficient'], color=colors)
plt.show()

# Сколько признаков обнулил Lasso?
n_zero = (lasso_model.coef_ == 0).sum()
print(f"Lasso обнулил: {n_zero} из {len(lasso_model.coef_)}")

Ключевые формулы

📈 Модели

ŷ = w₀ + w₁x₁ + ... + wₚxₚ
LRidge = MSE + α·Σwⱼ²
LLasso = MSE + α·Σ|wⱼ|

📊 Метрики

MSE = (1/n)·Σ(yᵢ − ŷᵢ)²
RMSE = √MSE
R² = 1 − SSres/SStot

🛠️ Предобработка

z = (x − μ)/σ
y' = log(1 + y)
IQR = Q₃ − Q₁

🔄 Кросс-валидация

CVK = (1/K)·Σ Metricᵢ
σ = √[(1/(K-1))·Σ(Metricᵢ − CVK)²]

Когда какую модель использовать

📊 Ridge

  • Все признаки полезны
  • Есть мультиколлинеарность
  • Нужна стабильность

🎯 Lasso

  • Нужен отбор признаков
  • Много «шумных» признаков
  • Хотим интерпретируемость

🔀 ElasticNet

  • Признаки коррелированы
  • Хотим лучшее из L1 и L2
  • Lasso нестабилен

📉 OLS

  • Признаков мало (p << n)
  • Нет мультиколлинеарности
  • Данные «чистые»

Ключевые выводы и источники

Топ-10 правил регрессии

  1. Регрессия — предсказание непрерывной величины. Классификация — дискретной.
  2. OLS минимизирует MSE. Решение: ŵ = (XᵀX)⁻¹Xᵀy.
  3. Ridge (L2) уменьшает веса, Lasso (L1) обнуляет их — отбор признаков.
  4. ElasticNet — компромисс между Ridge и Lasso.
  5. Логарифмирование скошенной целевой улучшает нормальность и гомоскедастичность.
  6. Пропуски бывают смысловыми (→"None") и случайными (→ медиана).
  7. Выбросы удаляются методом IQR или Z-score. Только из train!
  8. Кросс-валидация даёт устойчивую оценку. GridSearchCV — оптимальные гиперпараметры.
  9. fit_transform только на train. transform на test.
  10. R² — доля объяснённой дисперсии. RMSE — средняя ошибка в единицах целевой.
