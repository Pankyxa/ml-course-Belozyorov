📈 Что такое регрессия?

Регрессия — это класс задач машинного обучения с учителем, в которых целевая переменная является непрерывной величиной. Модель учится предсказывать число, а не метку класса.

📐 Математическая постановка

Дано: обучающая выборка

D = {(x₁, y₁), ..., (xₙ, yₙ)}
  • xᵢ ∈ ℝᵖ — вектор из p признаков
  • yᵢ ∈ ℝ — непрерывная целевая

Найти: функцию f: ℝᵖ → ℝ, минимизирующую ошибку.

🎯 Ключевая идея

Модель подбирает параметры так, чтобы предсказания были как можно ближе к истинным значениям.

«Близость» измеряется функцией потерь (MSE, MAE и др.).

📉 Линейная регрессия — базовая модель

📐 Уравнение модели

ŷ = w₀ + w₁·x₁ + w₂·x₂ + ... + wₚ·xₚ

где w₀ — смещение (bias), w₁,...,wₚ — веса (коэффициенты)

📊 В матричной форме

ŷ = X·w
  • X ∈ ℝⁿˣ⁽ᵖ⁺¹⁾ — матрица признаков
  • w ∈ ℝᵖ⁺¹ — вектор весов
  • n — число объектов
  • p — число признаков

💡 Идея

Модель предполагает линейную зависимость целевой от признаков.

Каждый признак влияет на целевую независимо с весом wⱼ.

Признаки должны быть числовыми (или закодированными).

06

📐 Метод наименьших квадратов (OLS)

OLS (Ordinary Least Squares) — находит веса, при которых сумма квадратов отклонений предсказаний от истинных значений минимальна.

📊 Функция потерь (MSE)

L(w) = (1/n) · Σᵢ (yᵢ − ŷᵢ)²

🧮 Аналитическое решение

Чтобы найти минимум, берём производную по w и приравниваем к нулю:

ŵ = (XᵀX)⁻¹·Xᵀ·y

Это нормальное уравнение. Работает, если XᵀX обратима.

⚠️ Проблемы OLS

  • Переобучение при p ≈ n или p > n
  • Мультиколлинеарность → XᵀX плохо обусловлена
  • Выбросы сильно искажают веса
  • Скошенность целевой нарушает предпосылки
07

✅ Свойства OLS-оценки

🎯 Несмещённость

E[ŵ] = wtrue

В среднем оценка совпадает с истинными весами при выполнении предпосылок.

⚡ Эффективность

Наименьшая дисперсия среди всех несмещённых линейных оценок.

Теорема Гаусса-Маркова.

📈 Состоятельность

ŵ → wtrue при n → ∞

С ростом данных оценка улучшается.

📋 Предпосылки теоремы Гаусса-Маркова

#ПредпосылкаЧто означает
1Линейностьy = w·x + ε
2Случайная выборка(xᵢ, yᵢ) независимы
3Нулевое условное среднееE[ε | x] = 0
4ГомоскедастичностьVar(ε | x) = σ² (константа)
5Нет мультиколлинеарностиXᵀX обратима
08

⚖️ Зачем нужна регуляризация?

🚨 При большом числе признаков (в House Prices — 79) OLS-решение переобучается: модель запоминает шум в обучающих данных, а на новых данных показывает плохой результат.

⚠️ Симптомы переобучения

  • Ошибка на train очень низкая
  • Ошибка на test высокая
  • Веса модели огромные по модулю
  • Модель чувствительна к малейшим изменениям

✅ Идея регуляризации

Добавить штраф за большие веса к функции потерь.

L = MSE + α · Штраф(w)

Это заставляет модель искать простое решение.

09

🔷 Ridge-регрессия (L2-регуляризация)

📐 Функция потерь

LRidge(w) = MSE + α · Σⱼ wⱼ²

🧮 Аналитическое решение

ŵ = (XᵀX + αI)⁻¹·Xᵀ·y

Добавление αI гарантирует обратимость матрицы XᵀX даже при мультиколлинеарности.

💡 Свойства

  • Веса уменьшаются, но не обнуляются
  • Хорошо работает при мультиколлинеарности
  • Не выполняет отбор признаков
  • Эквивалентна MAP-оценке с гауссовским априорным распределением
💡 Выбор α: чем больше α — тем сильнее штраф. При α → 0 получаем OLS. При α → ∞ все веса → 0.
10

🎯 Lasso-регрессия (L1-регуляризация)

📐 Функция потерь

LLasso(w) = MSE + α · Σⱼ |wⱼ|

💡 Ключевая идея

L1-штраф имеет «углы» на осях. При оптимизации минимум часто попадает именно в угол — некоторые веса точно обнуляются.

Это делает Lasso встроенным механизмом отбора признаков.

✨ Свойства Lasso

  • Автоматический отбор признаков
  • Разреженное решение (sparse)
  • Устойчивость к выбросам
  • Эквивалентна MAP с лапласовским априорным
⚠️ Осторожно: при сильно коррелированных признаках Lasso выбирает произвольный — может оставить «не тот».
11

📐 Геометрическая интерпретация

Регуляризация — это ограничение на область допустимых весов. Форма ограничения определяет поведение:

⭕ Ridge (L2)

Ограничение: ||w||₂² ≤ t — круг (сфера в p-мерном пространстве)

Минимум MSE + штраф обычно касается границы круга — обе координаты ненулевые.

➡️ Веса уменьшаются, но не обнуляются.

💎 Lasso (L1)

Ограничение: ||w||₁ ≤ t — ромб

У ромба есть вершины на осях. Минимум часто попадает в угол — одна координата обнуляется.

➡️ Автоматический отбор признаков!

🎯 Именно форма ограничения (круг vs ромб) объясняет разницу в поведении Ridge и Lasso.
12

🔀 ElasticNet — компромисс

📐 Функция потерь

L(w) = MSE + α · (ρ·Σ|wⱼ| + (1−ρ)/2 · Σwⱼ²)

где α — общая сила регуляризации, ρ ∈ [0, 1] — баланс L1/L2

💡 Идея

Комбинирует отбор признаков (L1) и устойчивость (L2).

  • ρ = 0 → чистый Ridge
  • ρ = 1 → чистый Lasso
  • 0 < ρ < 1 → компромисс

🎯 Преимущества

  • Работает лучше Lasso при коррелированных признаках
  • Работает лучше Ridge при большом числе признаков
  • Стабильнее Lasso
  • Может выбрать группу коррелированных признаков
⚠️ Минус: нужно подбирать два гиперпараметра (α и ρ) — дороже по времени.

📉 Обнаружение и обработка выбросов

🔢 Метод IQR

IQR = Q₃ − Q₁

Границы:

  • Нижняя: Q₁ − 1.5·IQR
  • Верхняя: Q₃ + 1.5·IQR

Не требует нормальности, устойчив к выбросам.

📊 Z-score

z = (x − μ) / σ

Правило: |z| > 3 → выброс.

Предполагает нормальность. Плохо работает на скошенных данных.

🔧 Модифицированный Z-score

M = 0.6745 · (x − median) / MAD

Использует медиану и MAD вместо среднего и std. Устойчив к выбросам.

🎯 В House Prices

Известные выбросы по документации Kaggle:

  • GrLivArea > 4000 кв. футов
  • SalePrice < $300 000

Удаляем только из train!

📉 Логарифмирование скошенной целевой

⚠️ Проблема скошенности

SalePrice имеет правую асимметрию (skew ≈ 1.88):

  • Большинство домов дешёвые
  • Несколько домов очень дорогие
  • Распределение далеко от нормального

Последствия: гетероскедастичность, большое влияние выбросов.

✅ Решение: log1p

y' = log(1 + y)

Обратное:

y = exp(y') − 1

skew после: ≈ 0.12 — почти нормальное!

⚠️ Важно: после логарифмирования метрики (RMSE) считаются в лог-пространстве. Для реального RMSE в долларах используйте np.expm1(predictions).

📏 Масштабирование признаков

📊 StandardScaler

z = (x − μ) / σ

mean = 0, std = 1

Для LR, Ridge, Lasso, SVM.

📐 MinMaxScaler

Диапазон [0, 1]

Для нейросетей.

Устойчив к выбросам

Для «грязных» данных.

📊 Метрики регрессии

📉 MSE — Mean Squared Error

MSE = (1/n)·Σ(yᵢ − ŷᵢ)²

Штрафует большие ошибки сильнее. Чувствителен к выбросам.

📈 RMSE

RMSE = √MSE

В единицах целевой (долларах). Чувствителен к выбросам.

📊 MAE

MAE = (1/n)·Σ|yᵢ − ŷᵢ|

Устойчива к выбросам. Соответствует медианной ошибке.

🎯 R²

R² = 1 − SS_res / SS_tot

Доля объяснённой дисперсии. 0..1 (может быть < 0).

🔄 Кросс-валидация (K-Fold)

⚠️ Проблема одного split

  • Оценка зависит от случайности
  • Маленький датасет → нестабильные метрики
  • Нет информации о разбросе качества

✅ Решение: K-Fold

  1. Разбить данные на K фолдов
  2. Обучить K раз (каждый фолд побывает в test)
  3. Усреднить метрики

🚨 Утечка данных (Data Leakage)

🚨 Утечка данных — ситуация, когда информация из test «просачивается» в train через preprocessing. Модель показывает нереально высокие метрики, но в продакшене «падает».

❌ Типичные ошибки

  • scaler.fit_transform(X_all) до split
  • Вычисление медианы на всём датасете
  • Target Encoding до split
  • Feature selection по всем данным
  • Удаление выбросов из test

✅ Правильно

  • Сначала train_test_split
  • fit только на train
  • transform на test с train-параметрами
  • Использовать Pipeline
  • Target Encoding внутри CV
# ❌ НЕПРАВИЛЬНО — утечка! scaler = StandardScaler() X_all_scaled = scaler.fit_transform(X_all) # fit на всех данных! X_train, X_test, y_train, y_test = train_test_split(X_all_scaled, y) # ✅ ПРАВИЛЬНО X_train, X_test, y_train, y_test = train_test_split(X, y) scaler = StandardScaler() X_train_scaled = scaler.fit_transform(X_train) # только train! X_test_scaled = scaler.transform(X_test) # transform на test

⚖️ Переобучение и недообучение

📉 Underfitting

Train error: высокий
Test error: высокий

Модель слишком простая.

Решение: усложнить модель, больше признаков, меньше регуляризации.

✅ Optimum

Train error: низкий
Test error: низкий

Модель обобщает.

Кросс-валидация даёт стабильные метрики.

📈 Overfitting

Train error: очень низкий
Test error: высокий

Модель запомнила шум.

Решение: регуляризация, больше данных, упрощение.

📐 Все ключевые формулы

📈 Модели

ŷ = w₀ + w₁x₁ + ... + wₚxₚ
LRidge = MSE + α·Σwⱼ²
LLasso = MSE + α·Σ|wⱼ|

📊 Метрики

MSE = (1/n)·Σ(yᵢ − ŷᵢ)²
RMSE = √MSE
R² = 1 − SSres/SStot

🛠️ Предобработка

z = (x − μ)/σ
y' = log(1 + y)
IQR = Q₃ − Q₁

🔄 Кросс-валидация

CVK = (1/K)·Σ Metricᵢ
σ = √[(1/(K-1))·Σ(Metricᵢ − CVK)²]

1

🎯 Когда какую модель использовать

📊 Ridge — используем, когда:

  • Все признаки полезны
  • Есть мультиколлинеарность
  • Много признаков, но каждый вносит вклад
  • Нужна стабильность

🎯 Lasso — используем, когда:

  • Нужен отбор признаков
  • Много «шумных» признаков
  • Хотим интерпретируемость
  • Хотим уменьшить размерность

🔀 ElasticNet — используем, когда:

  • Признаки коррелированы
  • Хотим взять лучшее из L1 и L2
  • Lasso нестабилен
  • Ridge оставляет слишком много признаков

📉 OLS — используем, когда:

  • Признаков мало (p << n)
  • Нет мультиколлинеарности
  • Нужно максимально простое решение
  • Данные «чистые»
