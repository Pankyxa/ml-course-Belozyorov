# Titanic — Machine Learning from Disaster

**Источник:** [Kaggle Competition](https://www.kaggle.com/c/titanic)  
**Файлы:** `train.csv` (891 строка), `test.csv` (418 строк)  
**Задача:** бинарная классификация — выжил пассажир (`Survived = 1`) или нет (`Survived = 0`).

## Состав выборок

| Выборка | Строк | Столбцов | Целевая переменная |
|---------|------:|---------:|--------------------|
| train   | 891   | 12       | `Survived` есть    |
| test    | 418   | 11       | `Survived` нет (её предсказывает модель) |

Признаков в исходной таблице 11, плюс целевой столбец `Survived` в обучении.

## Столбцы

| Столбец | Тип | Описание | Пропуски в train |
|---------|-----|----------|------------------:|
| PassengerId | int | Идентификатор пассажира, в модель не входит | 0 (0%) |
| Survived | int (0/1) | Целевая переменная: 0 — не выжил, 1 — выжил | 0 (0%) |
| Pclass | int (1/2/3) | Класс билета: 1 — высший, 3 — низший | 0 (0%) |
| Name | str | ФИО. В базовой модели не используется | 0 (0%) |
| Sex | str | Пол: `male` / `female` | 0 (0%) |
| Age | float | Возраст в годах, есть дробные значения у младенцев | 177 (19.9%) |
| SibSp | int | Число братьев, сестёр и супругов на борту | 0 (0%) |
| Parch | int | Число родителей и детей на борту | 0 (0%) |
| Ticket | str | Номер билета | 0 (0%) |
| Fare | float | Стоимость билета | 0 (0%) |
| Cabin | str | Номер каюты | 687 (77.1%) |
| Embarked | str | Порт посадки: C — Cherbourg, Q — Queenstown, S — Southampton | 2 (0.2%) |

Числовые столбцы: `PassengerId`, `Survived`, `Pclass`, `Age`, `SibSp`, `Parch`, `Fare`.  
Категориальные столбцы: `Name`, `Sex`, `Ticket`, `Cabin`, `Embarked`.

## Баланс классов (train)

| Класс | Смысл | Количество | Доля |
|-------|--------|------------:|-----:|
| 0 | Не выжил | 549 | 61.6% |
| 1 | Выжил | 342 | 38.4% |

Классы несбалансированы: погибших примерно в 1.6 раза больше, чем выживших. Из-за этого одной accuracy недостаточно — рядом смотрим precision, recall, F1 и ROC-AUC.
